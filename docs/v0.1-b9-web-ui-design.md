# v0.1-b9 设计文档：Web UI MVP

## 背景

v0.1-b8 完成了统一搜索和库报告，CLI 功能已经覆盖核心工作流。但 CLI 对非技术用户（音频制作人）不友好，无法试听、无法快速浏览结果、无法直观管理标签。

**用户目标：**
1. 可视化搜索 — 看到结果列表，点击试听
2. 快速管理 — 编辑标签、查看报告，不用记命令
3. 产品化验证 — 确认音频制作人是否真的愿意用 AMM 管理样本

**产品路线：**
- Phase 1（本版本）：FastAPI + Web UI，验证核心工作流
- Phase 2：体验打磨（波形、批量操作、收藏）
- Phase 3：Tauri 桌面包装，面向圈子推广

**技术选型：**
- 后端：FastAPI + Uvicorn（Python，复用现有核心）

- 音频播放：HTML5 `<audio>` 元素
- 数据格式：JSON（与 CLI 共享同一份 library.json）

## API 设计

### 1. 搜索接口

```
GET /api/search?q={query}&limit={n}
```

**参数：**
- `q`：搜索文本（支持自然语言，如"暗的 loop 120bpm"）
- `limit`：返回数量（默认 20）

**响应：**
```json
{
  "query": "暗的 loop 120bpm",
  "strategy": "rule_filter + semantic_sort",
  "total": 23,
  "results": [
    {
      "id": "abc123",
      "file_name": "dark_pad_loop_120bpm.wav",
      "file_path": "/audio/packs/dark_pad_loop_120bpm.wav",
      "duration_sec": 4.0,
      "tempo_bpm": 120,
      "brightness": "dark",
      "is_loop": true,
      "tags": ["pad", "loop", "dark"],
      "score": 0.92
    }
  ]
}
```

### 2. 音频播放接口

```
GET /api/audio/{file_path}
```

**说明：** 直接返回音频文件，浏览器用 `<audio>` 播放。
**安全：** 只允许访问配置的样本库目录内的文件。

### 3. 库报告接口

```
GET /api/report
```

**响应：**
```json
{
  "total_files": 1562,
  "format_distribution": {"wav": 1200, "aiff": 300, "flac": 62},
  "type_distribution": {"loop": 900, "one_shot": 662},
  "tag_coverage": {
    "auto_tag": {"count": 1562, "percent": 100},
    "semantic": {"count": 420, "percent": 27},
    "review": {"count": 89, "percent": 6}
  },
  "top_tags": [
    {"tag": "kick", "count": 180},
    {"tag": "snare", "count": 150}
  ]
}
```

### 4. 样本详情接口

```
GET /api/sample/{id}
```

**响应：** 完整的样本元数据（含 review.overrides、features 等）

### 5. 编辑标签接口

```
PUT /api/sample/{id}/review
```

**请求体：**
```json
{
  "overrides": {
    "derived.is_loop": false,
    "derived.brightness": "dark"
  },
  "notes": "手动修正：实际为 one-shot"
}
```

## 实现计划

| 子任务 | 文件 | 说明 | 依赖 |
|--------|------|------|------|
| T1 | `web_server.py` | FastAPI 服务主入口，路由注册 | 无 |
| T2 | `web/api_search.py` | 搜索 API（调用 unified_search） | T1 |
| T3 | `web/api_audio.py` | 音频文件流式返回 | T1 |
| T4 | `web/api_report.py` | 报告 API（调用 report） | T1 |
| T5 | `web/api_sample.py` | 样本详情 + 编辑 API | T1 |
| T6 | `web/static/index.html` | 搜索主页 | T2, T3 |
| T7 | `web/static/report.html` | 报告页 | T4 |
| T8 | `web/static/app.js` | 前端交互逻辑 | T6, T7 |
| T9 | `web/static/style.css` | 样式 | T6, T7 |
| T10 | `tests/test_web_api.py` | API 测试 | T2-T5 |
| T11 | `requirements.txt` | 添加 fastapi, uvicorn | 无 |

**任务依赖图：**

```
T1 (FastAPI 主入口)
├── T2 (搜索 API)  → T6 (搜索页)  → T8 (JS)  → T10 (测试)
├── T3 (音频 API)  → T6
├── T4 (报告 API)  → T7 (报告页)  → T8
└── T5 (编辑 API)  → T6
T9 (CSS) 独立
T11 (依赖) 独立
```

**并行执行机会：**
- T2, T3, T4, T5 可并行（都是独立 API）
- T6, T7 可并行（独立页面）
- T9, T11 独立

## 验收标准

```bash
# 1. 启动服务
python web_server.py
# 或
uvicorn web_server:app --reload

# 2. 浏览器打开 http://localhost:8000

# 3. 搜索功能
# - 输入 "kick drum"，返回结果列表
# - 输入 "暗的 loop 120bpm"，返回过滤结果
# - 点击 ▶ 能播放音频

# 4. 报告功能
# - 访问 /report 页面，显示库统计

# 5. 编辑功能
# - 点击样本，修改标签，保存成功

# 6. 测试通过
pytest tests/test_web_api.py -v

# 7. 不破坏现有 CLI
pytest tests/ -v
```

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 大库搜索慢 | 用户体验差 | 加缓存，限制返回数量 |
| 音频格式不兼容 | 无法播放 | 转码为 WAV/MP3，或提示格式 |
| 文件路径安全 | 漏洞 | 限制访问范围为配置的样本目录 |
| 前端太简陋 | 不像产品 | Phase 2 打磨，先验证功能 |
