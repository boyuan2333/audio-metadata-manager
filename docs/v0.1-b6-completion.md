## What Was Built

### Phase 1: CLAP Embedding Computation ✅
- `audio_metadata/clap_embed.py` — Core CLAP module
  - `load_clap_model()` — Load pre-trained CLAP model
  - `compute_audio_embedding()` — Compute embedding for single audio file
  - `compute_text_embedding()` — Compute embedding for text query
  - `compute_embeddings_batch()` — Batch process audio files
  - `cosine_similarity()` — Vector similarity computation
  - `search_similar()` — Find similar embeddings by cosine similarity

- `clap_embed_cli.py` — CLI for batch embedding
  - `app.py compute-embeddings --input <dir> --output <json>`

- `tests/test_clap_embed.py` — 14 tests (all passing)

### Phase 2: Semantic Search ✅
- `semantic_search_cli.py` — CLI for pure semantic search
  - `app.py semantic-search --query "<natural language>" --embeddings <json>`

- Integrated search functions in `audio_metadata/clap_embed.py`

### Phase 3: Hybrid Search ✅
- `audio_metadata/hybrid_search.py` — Hybrid search module
  - `hybrid_search()` — Combined rule-based + semantic search
  - `_matches_intent()` — Rule-based filtering (BPM, duration, keyword, status)
  - `format_hybrid_results()` — Terminal output formatting

- `hybrid_search_cli.py` — CLI for hybrid search
  - `app.py hybrid-search --query "<natural language>" --input <library> --embeddings <json>`

## Usage Examples

### Compute Embeddings (one-time setup)
```bash
python app.py compute-embeddings --input ./audio --output embeddings.json -v
```

### Pure Semantic Search
```bash
python app.py semantic-search --query "dark pad" --embeddings embeddings.json --top-k 10 -v
```

### Hybrid Search (recommended)
```bash
python app.py hybrid-search \
  --query "dark pad around 120 bpm" \
  --input library.json \
  --embeddings embeddings.json \
  --top-k 10 \
  -v
```

## Installation (Optional)

CLAP features are **opt-in**. Users without CLAP can still use all existing features.

```bash
# Core features only (no CLAP)
pip install -r requirements.txt

# With CLAP semantic search
pip install -r requirements-optional.txt
```

---

## Design Decisions

1. **Separate embeddings file** — Doesn't pollute main `library.json`, keeps schema v1 clean
2. **Graceful degradation** — Helpful error messages when CLAP not installed
3. **Hybrid approach** — Rule-based filtering first (fast), then CLAP re-ranking (accurate)
4. **Mock-based tests** — CI doesn't need CLAP installation, tests run fast
